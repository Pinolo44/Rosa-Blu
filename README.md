# Rosa-Blu
Progettazione di un rpg per il corso di metodologie di programmazione
L'interfaccia è realizzata tramite JavaFX
Il giocatore è un barista: serve clienti, guadagna soldi, migliora le sue statistiche e
sblocca nuove abilità giorno dopo giorno.


## Requisiti

- Java 25 (JDK)
- Nessuna installazione di Gradle: usa il wrapper incluso

## Come eseguire

    ./gradlew build
    ./gradlew run

Su Windows usa `gradlew.bat` al posto di `./gradlew`.
